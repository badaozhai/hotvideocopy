# 镜头语言与表演设计手册

写 beat sheet 和分镜时的取词工具书。核心原则:**心情不许用嘴说,用神态、动作、镜头说**。
(Show, don't tell —— 旁白讲"我很紧张" = 失败;手悬在门铃前收回来 = 成功)

## 一、情绪的外化词典(表演层)

每种心情都有一组可拍的身体语言。写表演拍时从这里选 1-2 个,写进 I2V prompt:

| 情绪 | 神态/动作(可直接进 prompt) |
|---|---|
| 忐忑/紧张 | 抬手欲按门铃又缩回、深呼吸、在门口小幅踱步、手心在裤子上擦、反复整理衣领/头发、咽口水 |
| 急切/期待 | 小跑、步频加快、频繁看手机时间、踮脚张望、听到铃声立刻起身、快步中差点绊到 |
| 惊讶→惊喜 | 愣住定格一拍 → 睁大眼 → 捂嘴 → 绽开笑(注意:必须分拍,一步到位就假) |
| 愧疚/歉意 | 低头、不敢对视、双手递物、鞠躬、搓手、雨中站着不动等发落 |
| 感动 | 抿嘴、眼眶湿、接过东西时动作放轻放慢、低头看手里的东西再抬头 |
| 释然/温暖 | 长出一口气、靠在门框上笑、摇头笑、目送 |
| 失落/自责 | 蹲下、雨中呆坐、盯着摔烂的东西不动、慢动作收拾 |
| 犹豫/下决心 | 停步 → 回头 → 再转身 → 攥拳 → 迈步(决心是"回头之后再向前"拍出来的) |

**道具是情绪放大器**:摔烂的餐盒(自责)、干毛巾(善意)、向日葵(感谢)、
手写便签(郑重)、两杯奶茶里递出一杯(分享)。给道具单独的 insert 特写。

## 二、景别:拍多近 = 说多深

| 景别 | 用途 | prompt 词 |
|---|---|---|
| 大远景 | 处境/孤独(雨夜空街上一个人) | extreme wide shot, tiny figure in the frame |
| 全景 | 动作全貌(摔车、奔跑) | wide shot, full body |
| 中景 | 双人关系、动作交互(递毛巾) | medium shot |
| 近景 | 对话、上半身反应 | medium close-up |
| 特写 | **情绪与决定性瞬间**(愣住的脸、欲按又止的手) | close-up on her face / on his trembling hand |
| 大特写/insert | 道具信息(便签字迹、门铃按钮、手机屏幕) | extreme close-up, insert shot |

规律:**情绪节点必须给到特写**。全片没有一个脸部特写 = 观众进不去人物内心。

## 三、机位与角度:摄影机站在谁的立场

| 手法 | 情绪效果 | prompt 词 |
|---|---|---|
| 平视 | 平等、亲近(两人对话默认) | eye-level |
| 低角度仰拍 | 人物高大/压迫 | low angle |
| 高角度俯拍 | 弱小、受困(摔在雨里) | high angle looking down |
| 过肩镜头 | 对话的关系感、正反打基础 | over-the-shoulder shot |
| POV 主观镜头 | 代入(他看见门开了/她看见花) | POV shot, from his point of view |
| 门框/窗框构图 | 隔阂、期待被打开(门里门外) | framed by the doorway |
| 前景遮挡 | 窥视感、距离感 | shot through foreground objects |

## 四、运镜:摄影机的动作就是情绪的动作

| 运镜 | 情绪效果 | prompt 词 |
|---|---|---|
| 缓推(push in) | 走进内心、聚焦决定瞬间 | slow push-in |
| 拉远(pull back) | 揭示处境、孤独、收尾 | slow pull back revealing |
| 跟拍 | 伴随、紧迫(跟着小跑) | tracking shot following him |
| 手持微晃 | 不安、纪实感(抖音实拍味) | subtle handheld camera |
| 静止固定 | 压抑、凝重、让表演自己说话 | static camera |
| 升降/摇 | 空间交代、情绪升华 | crane up / slow pan |

规律:**内心戏用缓推,奔跑用跟拍,尴尬/沉重用静止**。一镜一个运镜意图,别堆砌。

## 五、剪辑语法(排 timeline 时用)

- **正反打**:对话在两人近景间切换,谁说话/谁反应各给镜头。一场对话至少 2-3 切。
- **反应镜(reaction shot)**:A 做了重要动作,必须切 B 的反应——反应比动作更传情。
- **insert 特写**:对话中插道具特写(便签、花、毛巾),节奏喘息 + 信息强调。
- **J-cut / L-cut 声画桥接**:下一镜的声音先进来(铃声先响,再切她起身),已在用,保持。
- **节奏公式**:紧张段 = 短镜快切(2s 内);抒情段 = 长镜慢节奏(4-6s);
  高潮前刻意放一个静止长拍蓄力。
- **匹配剪辑**:动作衔接处剪(手按下门铃 → 门内铃响),因果感最强。

## 六、时序模板:一个 payoff 的标准拍法

以"上门送花"为例,完整的拍应该是(≠ 一个镜头):

```
铺垫   ① 全景跟拍:拎着东西小跑          (急切)
障碍   ② 特写:手悬在门铃前,缩回,深呼吸    (忐忑 ← 这拍最值钱)
行动   ③ 近景:闭眼按下门铃              (决心)
反应   ④ 门内中景:她闻铃快步走向门        (期待)
悬念   ⑤ 特写:门把手转动 / 他屏住呼吸     (蓄力半拍)
payoff ⑥ 近景正反打:门开,她愣住→惊喜,对白  (释放)
余韵   ⑦ insert:花/便签特写,或两人笑的定格  (回味)
```

**QC 口诀:铺垫拍、障碍拍、反应拍、余韵拍——四拍缺一即返工。**

## 七、grok I2V prompt 组装公式

`[景别/机位] + [角色+情绪外化动作(词典①)] + [运镜(词典④)] + [环境/光] + [对白 says in Chinese] + cinematic realistic`

例:`Close-up: the delivery man's hand hovers over the doorbell, pulls back, he takes
a deep breath and wipes his palm on his uniform, slow push-in, warm afternoon light,
cinematic realistic, no speech`

注意:
- 一镜一个表演拍,动作别超过 2 个(grok 塞太多会赶戏)
- 情绪转变(愣住→笑)要在 prompt 里写"then",给转变留时间(5-6s 档)
- 无对白镜加 `no speech`,防它自己配话
