## 定妆照制作规范 v2(2026-08-10 用户定稿)

风格基线:电影写真风格、超写实 photorealistic、8K超高清、电影质感、古装正剧风格;
摄影棚定妆照,渐变灰色背景,柔和均匀影棚柔光,干净光影,立体感强,画面清晰锐利。

**分格独立生成后拼接**(不要单图一次生成多视图,会互相污染):
- 左格(占总宽 40%):人物面部大特写胸像(中近景)
- 右格(占总宽 60%,可再分列):同一人物全身全景,不同角度(正面/3/4侧背/背面)
- 各格上下完全对齐、高度一致,格间细黑色竖线分割;同一人物、同一服装、同一光影

prompt 公式:【镜头运动】+【主体动作】+【场景环境】+【光线氛围】+【色调风格】+【画质词】
+ 人物核心身份设定 + 人物神态/情绪设定。已有单张定妆图时作为唯一 ref 锚定形象。

实现脚本:scripts/replica_pipeline/r7_sheets.py(3格生成+PIL 拼接)。
